# 网站审查与重构记录

审查日期：2026-09-30。范围：原首页与 23 份实验 HTML，其中四份为重复旧版本；重构后保留 19 个独立实验。

## 已修复的问题

| 问题 | 原因与影响 | 修复 |
| --- | --- | --- |
| 正态实验分组滑块不重绘 | 检查了始终为 `null` 的旧图表实例变量 | 改为判断实际样本是否存在，滑块重绘同一批样本 |
| 考试成绩分组与窗口变化不重绘 | 数据为对象，代码却检查 `.length` | 按对象键判断数据是否存在 |
| 输入平均分 0 被替换为 75 | `parseFloat(value) || 75` 把合法的 0 当成空值 | 用有限数值判断，保持 0；按控件边界规范输入 |
| 满分 100 漏画 | 总体直方图计数包含 100，分班柱形却使用全部半开区间 | 最后一组包含右端点 100，保持频率密度面积正确 |
| 参数与已生成样本混淆 | 重绘时从当前输入重新读取理论参数 | 保存本次模拟的模型参数；修改参数后重新运行才重新抽样 |
| 切换班级难以公平比较 | 旧页面选择班级后需重跑，重跑会改变原有班的成绩 | 每次模拟生成固定十班数据，切换班级直接比较本次固定成绩 |
| 样本标准差有提前舍入 | 分班标准差使用保留一位小数的均值 | 使用精确均值计算，仅在展示时舍入 |
| 迭代表达式负号优先级错误 | `-x^2` 被解析为 `(-x)^2` | 乘方先于一元负号；保留右结合与负指数支持 |
| 杨辉三角第 0 行公式错误 | 当 n=0 时省略了指数，显示为 `(a+b)=1` | 显示 `(a+b)⁰=1`；二项式标题使用真正的上标 |
| 杨辉三角键盘动作冲突 | 在按钮或三角单元上按 Enter/Space 仍触发页面快捷键 | 输入、链接、按钮有焦点时交给原生控件处理 |
| 等比数列参数与证据不同步 | 首项输入范围和滑块范围不同，数据表只展示最多 15 项 | 统一首项范围；数据表覆盖显示的全部项数 |
| 等比极限结论与边界参数脱节 | 固定结论无法反映 q=1、q=−1、a=0 等当前状态 | 按当前参数显示收敛、振荡、发散及退化情形说明 |
| 正态模拟教学表述过强 | 说明暗示“增加样本必然更正态”，且理论曲线颜色说错 | 说明正态生成前提、单次随机波动与实际成绩的模型限制；修正曲线颜色 |
| 正态函数振幅引起概念混淆 | A≠1 时仍容易被理解为概率密度 | 明确整条曲线面积为 A，只有 A=1 时为正态概率密度 |
| 主题状态不一致 | 首页和实验使用不同存储键，部分页面不持久化 | 共用主题和字号设置；存储不可用时仍可操作当前页面 |
| 页面小字、截断及控件溢出 | 原字号多为 12–15 px；标题省略；按钮组强制单行 | 正文和控件 20 px，大字 24 px；标题完整显示；控件按宽度换行 |
| 隐藏教学功能且无法统一聚焦 | 原统一层隐藏了速度、规模、随机、规则等控件 | 恢复教学功能；共用聚焦工具，底部保留实验操作 |
| 重复实验与首页遗漏 | 抽球、传球、杨辉三角和汉诺塔各有旧副本；高级抽样对照未列入首页 | 归档四个旧副本；将独立抽样对照实验加入目录；旧地址继续跳转 |
| 文件混放 | 大型 HTML 内混合 CSS/JS，历史备份与 macOS 元数据位于根目录 | 实验按主题分目录，样式/逻辑分文件；历史资料集中归档 |

## 首页与公共界面

首页按数列与极限、概率与组合、统计与分布、不等式与推理分组，加入关键词搜索、结果计数和空结果恢复。使用原生 SVG 表现数学图形，无外部素材依赖。卡片以完整中文名称和具体学习目标为主。

实验页共用返回目录、跨实验目录、主题、大字、聚焦和全屏控件。移除了重复主题工具，统一边框、卡片、按钮、表格与字体。浅色模式采用深色文字；深色模式使用明亮文字，固定深色坐标轴的统计图保留白色绘图区。彩色方块上的数字选择黑/白高对比前景，等比与迭代曲线随主题切换。

滑块与表格可读性提高；部分大量数据表在自身容器内横向滚动。开关补充了键盘操作、ARIA 状态与名称；目录对话框支持关闭和返回原按钮。聚焦模式可以继续操作，避免只剩静态图。

## 验证

- 静态检查：19 个实验、4 个分类、23 个旧地址；159 个本地文件引用存在，活动 HTML 无重复 ID，全部活动 JS 语法通过。
- 数学回归：负号/乘方优先级、右结合与负指数、等比边界求和、二项式指数、分组重绘、合法均值 0、满分柱形、模型快照、固定班级切换和输入限制。
- 浏览器：逐页执行全部 19 个实验的主要操作，未捕获运行错误；桌面宽度检查未发现整页横向溢出。
- 响应式：390 px 宽度逐页截图复查，19 个实验未发现整页横向溢出或按钮跑出视口；深色主题按此宽度逐页检查。
- 首页：主题筛选、搜索“二项”（概率类下 3 个匹配）、空结果和恢复 19 个实验。
- 课堂工具：深浅主题持久化、字号、目录弹窗、聚焦与底部演示操作。

验证覆盖主要课堂路径和已修复的问题，未对每个实验的所有随机样本、参数组合和动画时序做穷举。具体浏览器检查记录与截图放在 `docs/qa/`。
